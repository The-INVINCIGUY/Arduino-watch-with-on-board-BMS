

## This is no ordinary watch.


This is a super small (1x1.5inch!) and low powered ATMega328P-based watch with an OLED display, on board BMS, speaker, a super accurate and low power RTC, an on board USB to UART chip for easy programming and more!

So basically it's a mini Arduino UNO with components permanently attatched to some pins.

The monochrome display and small size makes it perfect for minimalists or people who want to look cool.

Also my first PCB ever!
